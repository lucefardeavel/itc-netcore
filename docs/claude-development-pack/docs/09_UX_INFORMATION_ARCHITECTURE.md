# UX Information Architecture

## Principle
One backend and permission model, adaptive UX by role, device and task.

## Admin desktop
- Dashboard
- Subscribers: All, Online Sessions, Activations, Expiring, Suspended
- Resellers: Tree, Sales, Pricing, Wallets
- Finance: Ledger, Transfers, Commissions, Transactions, Reconciliation
- Network: NAS/MikroTik, RADIUS, Sessions, Accounting, Diagnostics
- Services: Plans, Bandwidth, Pools, Vouchers
- Reports
- Audit
- Settings

## Reseller desktop
- Dashboard
- Subscribers: My Subscribers, Activations, Expiring
- Resellers: My Resellers, Sales
- Finance: Wallet, Ledger, Transfers, Commissions
- Plans/Pricing
- Reports
- Settings

## Sales
- Dashboard
- Subscribers
- Activations
- My Activity
- Profile

## Mobile/PWA reseller navigation
- Home
- Customers
- Quick Action (+)
- Wallet
- More

Quick Action may offer by capability:
- Add Subscriber
- Activate
- Renew
- Voucher only when an owner-approved reseller voucher model/capability exists
- Transfer Balance

## Tablet
Compact navigation plus split-view where useful, especially customer list + Subscriber 360.

## Primary product screens
1. Dashboard
2. Subscriber 360
3. Activation/Renew/Change flow
4. Wallet/Ledger
5. Reseller detail
